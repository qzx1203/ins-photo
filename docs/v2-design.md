# 拾光 V2 设计

## 使用流程

批量粘贴贴文链接 → 解析队列 → 查看图片预览 → 选择是否同时下载视频 → 保存到本地。

## 界面

- 顶部提供多行链接输入与解析操作，一行一个链接，忽略空行、按贴文去重。
- 保存设置集中展示文件夹、视频开关和本次会话的 Cookie 导入。
- 左侧队列展示每篇贴文的作者、媒体数量、处理状态和错误；点击一条切换右侧预览。
- 右侧以缩略图网格显示照片与视频封面。照片可点击放大，视频带清晰标识。
- 底部统一展示进度、开始、取消、失败重试和打开文件夹操作。

## 行为约定

- 默认只保存照片；勾选“同时下载视频”后，轮播中的视频与纯视频贴文也可保存为 MP4。
- 批量任务顺序处理，单条失败不会阻塞其他贴文，完成状态区分全部成功与部分失败。
- 已完成的文件保留；重试跳过有效的已有媒体，不覆盖同名损坏或冲突文件。
- 预览仅加载图片或视频封面，预览失败不会被误报为下载失败。
- 下载保持媒体原字节，照片与视频按照贴文中的原始位置编号。
- 不保存 Cookie、Cookie 文件路径或任务历史，仅记住用户选择的保存目录。

## 验证标准

- 多条链接去重、无效链接提示、失败后继续及失败项重试。
- 混合轮播与纯视频在视频开关两种状态下的下载内容准确。
- 图片预览加载、放大、切换任务时忽略旧结果，窗口关闭时安全结束后台任务。
- 图片和 MP4 完整性、重复跳过、取消后清理临时文件。
- 成品程序启动及退出通过检查；ZIP 解压后包含完整运行库并能独立启动。
